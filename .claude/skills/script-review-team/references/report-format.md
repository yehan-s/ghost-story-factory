# 评审报告格式说明

> 报告统一 9 节,固定顺序。Chief Editor 在汇总时遵照本格式。
> 占位符模板见 `templates/review-report.template.md`。

---

## 文件命名

- 路径:`docs/team-reviews/YYYY-MM-DD-<task-slug>.md`
- slug 规则:任务关键词 + 中文,不超过 30 字符,空格用短横线
- 示例:
  - `2026-05-07-状态密集化对讲机重构.md`
  - `2026-05-09-新增武汉剧本.md`
  - `2026-05-10-周目继承机制设计.md`

---

## 9 节结构

### § 1. 任务描述

字数:50-200 字
内容:
- 用户原话(如有)
- 助手对任务的理解概述
- 任务的影响范围(剧本 / 引擎 / UX / lore / 多层)

### § 2. Chief Editor — 首席编辑

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **层级判定**:剧本 / 引擎 / UX / lore / 多层(只有 Chief Editor 这一节有)
- **意见**:剧情连续性 / 悖论风险 / 伏笔影响
- **产出**(深度参与时):悖论清单 / 伏笔变更 / 一致性规范

### § 3. State Architect — 状态系统建筑师

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **意见**:状态层影响 / 重复体验消除 / 引擎扩展需求
- **产出**(深度参与时):新增 flags 命名清单 / variants 条件矩阵 / 引擎扩展需求

### § 4. Meta-Game Designer — 元游戏设计师

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **意见**:周目影响 / 收集本影响 / true ending 解锁影响
- **产出**(深度参与时):周目机制变更 / 收集本调整 / 解锁条件变化

### § 5. UX Designer — 文字体验设计师

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **意见**:玩家体验影响 / 文字节奏 / 状态可视化
- **产出**(深度参与时):TUI 草图 / 排版规范 / 玩家旅程节点变化

### § 6. Lore Keeper — 世界观考据师

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **意见**:lore 一致性 / 杭州本地质感 / 通用化风险
- **产出**(深度参与时):新增元素考据清单 / lore 不一致警告 / 命名建议

### § 7. Topology Designer — 拓扑设计师

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **意见**:拓扑结构影响 / 状态空间维度 / 可达性
- **产出**(深度参与时):节点结构变更图 / 状态维度调整 / 可达性证明

### § 8. QA / Path Tester — 路径测试官

字数:不限
固定子节:
- **相关度**:深度参与 / 普通审查 / 放行
- **意见**:可测试性 / 测试盲区
- **产出**(深度参与时):测试路径序列 / Bug 清单 / 回归测试入口

### § 9. 综合建议(Chief Editor 汇总)

字数:100-500 字
固定子节:
- **决议**:放行 / 修改后放行 / 打回
- **关键风险**(决议非"放行"时必填):列出最严重的 1-3 条
- **后续动作**:用户应该做什么(直接开干 / 用 writing-plans / 补充评审)
- **不同意见记录**(可选):有团队成员持保留意见时,在此记录,不阻塞放行决议

---

## 写作要点

- 放行者一句话即可,不要硬凑内容
- 深度参与者要有具体产出,空洞建议不算产出
- 决议是"放行"时,综合建议节可以简短(2-3 句)
- 决议是"打回"时,关键风险必须列具体节点 ID 或代码位置
- 引用相关 spec/ADR 时用相对路径
