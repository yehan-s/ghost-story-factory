# 相关度自报判定标准

> 7 个角色拿到任务描述 + Chief Editor 的层级判定后,
> 必须自报相关度。本文档是判定标准。

---

## 三档相关度

### 深度参与
- 任务核心影响在你的职责范围
- 你需要详细产出(具体设计/代码位置/Bug 清单)
- 你的产出是其他角色或开发阶段的输入

### 普通审查
- 任务局部影响在你的职责范围
- 你需要给出一段意见,但不需要详细方案
- 你的意见是参考,不阻塞

### 放行
- 任务与你的职责无关
- 你只需一句话:"无 X 影响,放行"
- X 是你的职责领域(剧情/状态/元游戏/UX/lore/拓扑/测试)

## 自报话术模板

### 深度参与
```
**相关度**:深度参与
**意见**:<2-5 段具体分析>
**产出**:<具体设计/清单/路径>
```

### 普通审查
```
**相关度**:普通审查
**意见**:<1-2 段简短意见>
```

### 放行
```
**相关度**:放行
**意见**:无 <职责领域> 影响,放行。
```

---

## 反模式(不要这样)

- ❌ "深度参与" + 空洞产出("建议关注 XX",没有具体内容)
- ❌ "放行" + 长段解释(放行就一句话)
- ❌ 自报相关度时还在等其他人的意见(应该独立判定)
- ❌ Chief Editor 越界帮其他角色判定相关度(每人自报)
